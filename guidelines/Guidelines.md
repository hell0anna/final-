## Design System Setup — MANDATORY

This project uses the repository-local YC web core in `src/vendor/yclients-ui`.
Before writing any code:

1. Keep the compiled runtime and stylesheet unchanged to preserve the design system.
2. Apply project styling through the existing YC tokens in `styles/global.css` and
   `src/index.css`.
3. Do not replace YC components with generic controls when an existing component
   already provides the required behavior.
