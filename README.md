# Промокоды YCLIENTS

Интерактивный прототип B2B-раздела управления промокодами. Проект построен на React, TypeScript и Vite. Компоненты YCLIENTS и шрифт Inter хранятся в репозитории, поэтому после сборки приложению не нужны Figma Registry, Google Fonts или внешний CDN.

## Что понадобится

1. Установите [Node.js 22](https://nodejs.org/).
2. Установите pnpm версии 10:

   ```bash
   npm install --global pnpm@10.34.3
   ```

Команды ниже нужно выполнять в терминале из папки проекта.

## Установка зависимостей

```bash
pnpm install
```

Версии пакетов зафиксированы в `pnpm-lock.yaml`. Не удаляйте этот файл перед публикацией.

## Локальный запуск

```bash
pnpm run dev
```

Vite напечатает локальный адрес, обычно `http://localhost:8443`. Откройте его в браузере. Остановить сервер можно сочетанием `Ctrl+C`.

## Проверка и production-сборка

```bash
pnpm run typecheck
pnpm run build
```

Команда сборки также запускает проверку TypeScript. Готовые статические файлы появятся в папке `dist/`.

При необходимости локально проверить именно собранную версию:

```bash
pnpm run preview
```

## Загрузка проекта в GitHub

1. Войдите на [GitHub](https://github.com/) и создайте новый пустой репозиторий. Не добавляйте через интерфейс GitHub README, `.gitignore` или лицензию.
2. В терминале из папки проекта выполните команды ниже. Замените `YOUR_NAME` и `YOUR_REPOSITORY` своими значениями:

   ```bash
   git add .
   git commit -m "Prepare app for deployment"
   git branch -M main
   git remote add origin https://github.com/YOUR_NAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

3. Если remote `origin` уже существует, не добавляйте его повторно. Проверить адрес можно командой `git remote -v`.

Файл `.gitignore` исключает зависимости, результаты сборки, локальные настройки Vercel и файлы с секретами.

## Публикация в Vercel

1. Войдите на [Vercel](https://vercel.com/) через GitHub.
2. Нажмите **Add New → Project** и выберите созданный репозиторий.
3. Vercel прочитает `vercel.json`. Проверьте параметры:
   - **Framework Preset:** Vite
   - **Install Command:** `pnpm install --frozen-lockfile`
   - **Build Command:** `pnpm run build`
   - **Output Directory:** `dist`
4. Поле **Root Directory** оставьте пустым, если `package.json` лежит в корне репозитория. Если в репозитории есть вложенная папка `V4`, укажите её как Root Directory.
5. Переменные окружения не требуются.
6. Нажмите **Deploy** и дождитесь статуса **Ready**.
7. После публикации нажмите **Visit** или скопируйте адрес вида `https://your-project.vercel.app`.

Каждый следующий push в ветку `main` будет автоматически создавать новый production-деплой. Pull request или push в другую ветку создаст Preview Deployment.

## Маршрутизация и внешние зависимости

Приложение является одностраничным прототипом и не использует URL-маршруты: все экраны переключаются внутри корневой страницы. Поэтому SPA rewrite на `index.html` не нужен и в `vercel.json` не добавлен.

Все необходимые шрифты, SVG и runtime-компоненты размещены локально и попадают в production-сборку. В текущей конфигурации приложение не вызывает сторонние API и не требует переменных окружения. Код Vite поддерживает опциональную Google Analytics-конфигурацию Figma Make, но аналитика не задана и внешний скрипт не подключается.

Доступность самого домена и инфраструктуры Vercel зависит от сети и провайдера пользователя и не может быть гарантирована настройками проекта.
